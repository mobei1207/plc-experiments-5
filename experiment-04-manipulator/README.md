# 实验四：机械手顺序控制

## 实验目的

1. 掌握位移位寄存器指令的使用及编程。
2. 掌握机械手控制系统的接线、调试、操作。

## 控制要求

1. 工件在 A 处被机械手抓取并放到 B 处。
2. 机械手回到初始状态，SQ4 = SQ2 = 1，SQ3 = SQ1 = 0，原位指示灯 HL 点亮。按下“SB1”启动开关，下降指示灯 YV1 点亮，机械手下降（SQ2 = 0），下降到 A 处后（SQ1 = 1）夹紧工件，夹紧指示灯 YV2 点亮。
3. 夹紧工件后，机械手上升（SQ1 = 0），上升指示灯 YV3 点亮，上升到位后（SQ2 = 1），机械手右移（SQ4 = 0），右移指示灯 YV4 点亮。
4. 机械手右移到位后（SQ3 = 1），下降指示灯 YV1 点亮，机械手下降（SQ2 = 0）。
5. 机械手下降到位后（SQ1 = 1），夹紧指示灯 YV2 熄灭，机械手放松。
6. 机械手放松后上升（SQ1 = 0），上升指示灯 YV3 点亮。
7. 机械手上升到位（SQ2 = 1）后左移，左移指示灯 YV5 点亮。
8. 机械手回到原点，此时如果启动开关依然为 ON，则机械手会立即循环以上运动过程。如果在机械手运行到任何一个地方断开启动开关，所有动作停止，需重新手动让机械手回原位，再进行以上过程。

## I/O 分配

完整 I/O 分配见 [`IO分配表.md`](IO分配表.md)。

简要说明：

- 启动开关 SB1 接 I0.0；
- 下限位开关 SQ1 接 I0.1，上限位开关 SQ2 接 I0.2，右限位开关 SQ3 接 I0.3，左限位开关 SQ4 接 I0.4；
- 下降指示灯 YV1 接 Q4.0，夹紧指示灯 YV2 接 Q4.1，上升指示灯 YV3 接 Q4.2，右移指示灯 YV4 接 Q4.3，左移指示灯 YV5 接 Q4.4，原位指示灯 HL 接 Q4.5；
- 主机输入 1M、2M 接电源 GND，面板 COM 接电源 GND；
- 主机 1L+、2L+ 接电源 +24V，面板 V+ 接电源 +24V。

## 接线说明

1. 按 I/O 分配表或接线图完成 PLC 与实训模块之间的接线。
2. 启动开关 SB1 和各限位开关 SQ1~SQ4 一端接 +24V，另一端接对应输入端子。
3. 各指示灯 YV1~YV5、HL 接对应输出端子，公共端接 GND。
4. 主机输入 1M、2M 接电源 GND，面板 COM 接电源 GND；主机 1L+、2L+ 接电源 +24V，面板 V+ 接电源 +24V。
5. 认真检查接线，确保正确无误后通电。

## 程序说明

- 程序使用位移位寄存器指令，按顺序控制机械手的各个动作。
- 初始状态：SQ4 = SQ2 = 1，SQ3 = SQ1 = 0，原位指示灯 HL 点亮。
- 按下 SB1 后，进入下降→夹紧→上升→右移→下降→放松→上升→左移的循环。
- 每个动作由对应的限位开关信号触发下一步。
- 若运行中断开启动开关，所有动作停止；重新启动前需手动使机械手回原位。

原程序见本文件夹下的 STEP7 工程文件。

## 调试过程

1. 检查实训设备中器材及调试程序。
2. 按照 I/O 分配表完成 PLC 与实训模块之间的接线，认真检查，确保正确无误。
3. 打开 STEP7 程序，编译无误后下载至 PLC。
4. 将 PLC 的 RUN/STOP 开关拨至 RUN 状态。
5. 确认机械手处于初始状态：SQ4 = SQ2 = 1，SQ3 = SQ1 = 0，原位指示灯 HL 点亮。
6. 按下“SB1”启动开关，观察机械手是否按控制要求依次动作。
7. 观察各限位开关信号是否能正确触发下一步动作。
8. 运行中断开启动开关，观察所有动作是否立即停止。
9. 重新使机械手回原位，再次启动，观察是否能正常循环。

调试中主要检查：

- 各限位开关信号是否能正常读入；
- 各指示灯是否按顺序点亮；
- 机械手动作顺序是否正确；
- 启动开关断开后是否立即停止；
- 重新启动前是否能正确回到原位。
