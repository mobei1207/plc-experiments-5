# 实验二：步进电机控制

## 实验目的

1. 掌握循环右移指令的使用及编程。
2. 掌握步进电机控制系统的接线、调试、操作。

## 控制要求

1. 利用可编程控制器输出信号控制步进电机运行。
2. 按下“SD”启动开关，系统准备运行。
3. 打开“MA”开关，系统进入手动控制模式，此时再按动“SE”单步按钮，步进电机运行一步。
4. 关闭“MA”开关，系统进入自动控制模式，此时步进电机开始自动运行。
5. 分别按动速度选择开关“V1”、“V2”、“V3”，步进电机运行在不同的速度段上。
6. 步进电机开始运行时为正转，按动“MF”开关，步进电机反方向运行。再按动“MZ”开关，步进电机正方向运行。

## I/O 分配

完整 I/O 分配见 [`IO分配表.md`](IO分配表.md)。

简要说明：

- 启动开关 SD 接 I0.0；
- 手动开关 MA 接 I0.1；
- 速度选择 V1、V2、V3 分别接 I0.2、I0.3、I0.4；
- 正转 MZ 接 I0.5，反转 MF 接 I0.6，单步 SE 接 I0.7；
- 步进电机 A、B、C、D 四相分别接 Q4.0~Q4.3；
- 主机 1M 接电源 GND，1L、2L、3L 接 +24V。

## 接线说明

1. 按 I/O 分配表或接线图完成 PLC 与实训模块之间的接线。
2. 步进电机 A、B、C、D 四相控制端接 Q4.0~Q4.3。
3. 各开关一端接 +24V，另一端接对应输入端子。
4. 主机 1M 接电源 GND，1L、2L、3L 接 +24V。
5. 认真检查接线，确保正确无误后通电。

## 程序说明

- 程序使用循环右移指令，依次输出四相脉冲，驱动步进电机转动。
- 手动模式下，按一次“SE”单步按钮，移位一次，电机走一步。
- 自动模式下，由定时器控制移位间隔，电机连续运行。
- 通过 V1、V2、V3 切换定时器时间常数，实现低速、中速、高速三档。
- MZ、MF 控制方向标志位，决定移位方向。

原程序见本文件夹下的 STEP7 工程文件。

## 调试过程

1. 检查实训设备中器材及调试程序。
2. 按照 I/O 分配表完成 PLC 与实训模块之间的接线，认真检查，确保正确无误。
3. 打开 STEP7 程序，编译无误后下载至 PLC。
4. 将 PLC 的 RUN/STOP 开关拨至 RUN 状态。
5. 按动“SD”启动开关，系统准备运行。
6. 打开“MA”开关，进入手动控制模式，按动一次“SE”单步按钮，步进电机运行一步。连续按动多次后，步进电机可运行一周。
7. 关闭“MA”开关，系统进入自动控制模式，步进电机开始自动运行。
8. 按动“V1”，步进电机低速运行；按动“V2”，中速运行；按动“V3”，高速运行。
9. 按动“MF”开关，步进电机反向运行；再按动“MZ”开关，恢复正转。

调试中主要检查：

- 四相输出顺序是否正确；
- 单步按钮是否灵敏，单步是否只走一步；
- 三档速度切换是否正常；
- 正反转切换是否正常。
