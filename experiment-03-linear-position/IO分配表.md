# 实验三：直线运动位置检测、定位控制 I/O 分配表

## PLC 地址与面板端子对应关系

| 序号 | PLC 地址（PLC 端子） | 电气符号（面板端子） | 功能说明 |
|------|----------------------|----------------------|----------|
| 1 | I0.0 | SD | 启动开关 |
| 2 | I0.1 | S1 | 光电传感器 1 |
| 3 | I0.2 | S2 | 光电传感器 2 |
| 4 | I0.3 | S3 | 光电传感器 3 |
| 5 | I0.4 | S4 | 光电传感器 4 |
| 6 | Q0.0 | MZ | 电机正转 |
| 7 | Q0.1 | MF | 电机反转 |
| 8 | Q0.2 | P1 | 位置 1 指示灯 |
| 9 | Q0.3 | P2 | 位置 2 指示灯 |
| 10 | Q0.4 | P3 | 位置 3 指示灯 |
| 11 | 1M、2M | — | 接电源 GND，面板 COM 接电源 GND |
| 12 | 1L+、2L+ | — | 接电源 +24V，面板 V+ 接电源 +24V |

## 说明

- 光电传感器 S1~S4 信号经低转高电平转换板接入 PLC 输入 I0.1~I0.4。
- PLC 输出 Q0.0~Q0.4 经高转低电平转换板驱动电机正反转与位置指示灯。
- 滑块运动规律：S1 → S2 → S1 → S3 → S1 → S4 → S1。
- 一个周期结束后若启动开关仍为 ON，则延时 4s 后重新循环。
- 断开启动开关，实训停止。
- 主机输入 1M、2M 接电源 GND，面板 COM 接电源 GND；主机 1L+、2L+ 接电源 +24V，面板 V+ 接电源 +24V。
