# 实验三：直线运动位置检测、定位控制

## 实验目的

1. 掌握字左移指令的使用及编程。
2. 掌握直线运动位置控制系统的接线、调试、操作。

## 控制要求

1. 利用直流电机带动滑块在各位置之间运动。
2. 系统启动后，直流电机开始正转，滑块沿导轨向右运行，当滑块经过光电开关时，光电开关给 PLC 发送一个位置信号，使其后面的位置指示灯点亮。
3. 滑块的一个周期运动规律为 S1 → S2 → S1 → S3 → S1 → S4 → S1。
4. 当一个周期结束后若启动开关仍处于 ON 状态，则 4s 后滑块仍按原规律运动，并按此循环，周而复始。
5. 断开启动开关，实训停止。

## I/O 分配

完整 I/O 分配见 [`IO分配表.md`](IO分配表.md)。

简要说明：

- 启动开关 SD 接 I0.0；
- 光电传感器 S1、S2、S3、S4 分别接 I0.1、I0.2、I0.3、I0.4；
- 电机正转 MZ 接 Q0.0，反转 MF 接 Q0.1；
- 位置指示灯 P1、P2、P3 分别接 Q0.2、Q0.3、Q0.4；
- 主机输入 1M、2M 接电源 GND，面板 COM 接电源 GND；
- 主机 1L+、2L+ 接电源 +24V，面板 V+ 接电源 +24V。

## 接线说明

1. 按 I/O 分配表或接线图完成 PLC 与实训模块之间的接线。
2. 光电传感器 S1~S4 信号经低转高电平转换板接入 PLC 输入 I0.1~I0.4。
3. PLC 输出 Q0.0~Q0.4 经高转低电平转换板驱动电机正反转与位置指示灯。
4. 启动开关 SD 一端接 +24V，另一端接 I0.0。
5. 主机输入 1M、2M 接电源 GND，面板 COM 接电源 GND；主机 1L+、2L+ 接电源 +24V，面板 V+ 接电源 +24V。
6. 认真检查接线，确保正确无误后通电。

## 程序说明

- 程序使用字左移指令，控制滑块在各位置之间的顺序运动。
- 启动后电机正转，滑块右行；每经过一个光电开关，对应位置指示灯点亮，并记录当前位置。
- 按 S1 → S2 → S1 → S3 → S1 → S4 → S1 的顺序循环。
- 一个周期结束后，若启动开关仍为 ON，则由定时器延时 4s 后重新开始下一周期。
- 断开启动开关，程序停止，电机停止运行。

原程序见本文件夹下的 STEP7 工程文件。

## 调试过程

1. 检查实训设备中器材及调试程序。
2. 按照 I/O 分配表完成 PLC 与实训模块之间的接线，认真检查，确保正确无误。
3. 打开 STEP7 程序，编译无误后下载至 PLC。
4. 将 PLC 的 RUN/STOP 开关拨至 RUN 状态。
5. 打开“启动”开关，直流电机开始正转，带动滑块沿导轨向右运行。
6. 当滑块经过光电开关 S1 时，光电开关发送给 PLC 一个位置信号，PLC 输出信号使位置指示灯 P1 点亮。
7. 观察滑块运动规律是否为 S1 → S2 → S1 → S3 → S1 → S4 → S1。
8. 一个周期结束后，若启动开关仍处于 ON，观察 4s 后是否重新循环。
9. 断开“启动”开关，观察实训是否停止。

调试中主要检查：

- 光电开关信号是否能正常读入；
- 位置指示灯是否按规律点亮；
- 电机正反转切换是否正常；
- 周期结束后延时 4s 是否准确；
- 启动开关断开后是否立即停止。
