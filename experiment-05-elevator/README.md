# 实验五：四层电梯控制

## 实验目的

1. 掌握复杂输入输出控制系统的程序编程技巧。
2. 掌握四层电梯控制系统的接线、调试、操作。

## 控制要求

1. 电梯由安装在各楼层电梯口的上升下降呼叫按钮（U1、U2、D2、D3、U3、D4）、电梯轿厢内楼层选择按钮（S1、S2、S3、S4）、上升下降指示（UP、DOWN）、各楼层到位行程开关（SQ1、SQ2、SQ3、SQ4）组成。电梯自动执行呼叫。

2. 电梯上升途中只响应上升呼叫，下降途中只响应下降呼叫，在二楼与三楼反方向的呼叫均无效（一楼与四楼除外）。

   例如，电梯停在一层，在三层轿厢外呼叫时，须按三层上升呼叫按钮，电梯才响应呼叫（从一层运行到三层），按三层下降呼叫按钮无效；反之，若电梯停在四层，在三层轿厢外呼叫时，必须按三层下降呼叫按钮，电梯才响应呼叫，按三层上升呼叫按钮无效，依此类推。电梯停止运行，同时有不同呼叫时，谁先呼叫执行谁的呼叫。

3. 具有呼叫记忆、内选呼叫指示功能，当呼叫执行完成解除锁定。

## I/O 分配

本实验共涉及 30 个 I/O 点，是五个实验里 I/O 最多的一个。

完整 I/O 分配见 [`IO分配表.md`](IO分配表.md)。

简要说明：

**输入（14 点）：**

- 轿厢内选按钮：S1、S2、S3、S4
- 电梯外呼按钮：U1、U2、U3、D2、D3、D4
- 楼层到位行程开关：SQ1、SQ2、SQ3、SQ4

**输出（16 点）：**

- 楼层指示：L1、L2、L3、L4
- 轿厢方向指示：UP、DOWN
- 内选指示：SL1、SL2、SL3、SL4
- 外呼指示：UP1、UP2、UP3、DN2、DN3、DN4

## 接线说明

1. 按 I/O 分配表或接线图完成 PLC 与实训模块之间的接线。
2. 各按钮、行程开关一端接 +24V，另一端接对应输入端子。
3. 各指示灯接对应输出端子，公共端接 GND。
4. 主机输入 1M、2M、3M 接电源 GND，面板 COM 接电源 GND。
5. 主机 1L+、2L+、3L+ 接电源 +24V，面板 V+ 接电源 +24V。
6. 认真检查接线，确保正确无误后通电。

## 程序说明

程序采用模块化结构，主要程序块如下：

| 程序块 | 名称 | 功能 |
|--------|------|------|
| OB1 | Main | 主循环，调用各功能块 |
| FC1 | 行程开关 | 读取各楼层行程开关状态，更新当前楼层数 |
| FC2 | 桥内面 | 轿厢内选按钮处理 |
| FC3 | 楼层登记 | 楼层呼叫登记与记忆 |
| FC4 | 内选灯控制 | 内选指示灯输出控制 |
| FC5 | 外呼 | 电梯外呼按钮处理 |
| FC6 | 外呼天 | 外呼指示灯输出控制 |

主要逻辑：

- 通过 MOVE 指令将行程开关状态写入数据块，记录当前楼层数。
- 呼叫登记使用置位/复位指令，实现呼叫记忆与解除锁定。
- 方向判断：电梯上行时只响应上行呼叫，下行时只响应下行呼叫。
- 二楼与三楼反方向呼叫无效，一楼只有上行呼叫，四楼只有下行呼叫。
- 电梯停止时，多个呼叫按先后顺序执行。

原程序见本文件夹下的 STEP7 工程文件。

## 调试过程

1. 检查实训设备中器材及调试程序。
2. 按照 I/O 分配表完成 PLC 与实训模块之间的接线，认真检查，确保正确无误。
3. 打开 STEP7 程序，编译无误后下载至 PLC。
4. 将 PLC 的 RUN/STOP 开关拨至 RUN 状态。
5. 将行程开关 SQ1 拨到 ON，SQ2、SQ3、SQ4 拨到 OFF，表示电梯停在底层。
6. 按下 U3，观察电梯方向指示灯 UP 和三层上呼指示 UP3 是否点亮。
7. 将 SQ1 拨到 OFF，底层指示灯 L1 熄灭，表明电梯离开底层。
8. 将 SQ2 拨到 ON，二层指示灯 L2 点亮，表明电梯到达二层；再将 SQ2 拨到 OFF，表示电梯离开二层。
9. 将 SQ3 拨到 ON 后再立即断开，表明电梯到达三层。
10. 重复以上步骤，按下不同的选择按钮，观察电梯的运行过程。

调试中主要检查：

- 各行程开关信号是否能正常读入，当前楼层数是否正确更新；
- 内选、外呼按钮是否能正常登记和记忆；
- 电梯上行/下行方向判断是否正确；
- 二楼、三楼反方向呼叫是否无效；
- 各指示灯是否按控制要求点亮；
- 多个呼叫时是否按先后顺序执行；
- 呼叫执行完成后是否解除锁定。

## 遇到的问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 电梯不响应呼叫 | 接线松动或 I/O 地址错误 | 检查接线，核对 I/O 分配表 |
| 顺向响应逻辑错误 | 方向判断程序或行程开关状态不对 | 重新核对控制要求，调整行程开关状态 |
| 指示灯不亮 | 输出端子未接 +24V 或 GND | 检查电源接线 |
| 当前楼层数不更新 | 行程开关信号未正确写入数据块 | 检查 MOVE 指令与数据块地址 |
| 呼叫无法解除 | 置位/复位逻辑错误 | 检查程序中的复位条件 |
