# plc-experiments

基于西门子 S7-300（CPU314C-2DP）的可编程控制器综合实验合集。

本仓库整理了内蒙古工业大学机械电子工程专业《可编程序控制器》实验课程中的五个实验，包含实验目的、控制要求、I/O 分配、接线图、梯形图截图、调试记录与演示视频。

> 说明：实验程序为课程提供的参考程序，本人负责电气接线、I/O 分配、传感器与执行器联调、功能验证与故障排查。

## 实验一：LED 数码显示

- **实验目的**：了解 PLC 软硬件结构，掌握段码指令与 LED 数码显示控制。
- **控制要求**：启动开关 K1 为 ON 时，八段数码管循环显示 0~F；断开启动按钮停止。
- **I/O 分配**：见 `experiment-01-led-display/IO分配表.md`
- **视频**：`experiment-01-led-display/media/demo.mp4`

---

## 实验二：步进电机控制

- **实验目的**：掌握循环右移指令，掌握步进电机控制系统的接线、调试、操作。
- **控制要求**：启动后系统准备；手动模式下按单步按钮走一步；自动模式下连续运行；V1/V2/V3 切换速度；MF 反转，MZ 正转。
- **I/O 分配**：见 `experiment-02-stepper-motor/IO分配表.md`
- **视频**：`experiment-02-stepper-motor/media/demo.mp4`

---

## 实验三：直线运动位置检测、定位控制

- **实验目的**：掌握字左移指令，掌握直线运动位置控制系统的接线、调试、操作。
- **控制要求**：滑块运动规律为 S1→S2→S1→S3→S1→S4→S1；一个周期结束后若启动开关仍为 ON，则 4s 后循环；断开启动开关停止。
- **I/O 分配**：见 `experiment-03-linear-position/IO分配表.md`
- **视频**：`experiment-03-linear-position/media/demo.mp4`

---

## 实验四：机械手顺序控制

- **实验目的**：掌握位移位寄存器指令，掌握机械手控制系统的接线、调试、操作。
- **控制要求**：工件在 A 处被机械手抓取并放到 B 处；按下 SB1 启动，机械手依次下降、夹紧、上升、右移、下降、放松、上升、左移回原点；断开启动开关所有动作停止。
- **I/O 分配**：见 `experiment-04-manipulator/IO分配表.md`
- **视频**：`experiment-04-manipulator/media/demo.mp4`

---

## 实验五：四层电梯控制

- **实验目的**：掌握复杂输入输出控制系统的程序编程技巧，掌握四层电梯控制系统的接线、调试、操作。
- **控制要求**：
  1. 电梯由各楼层电梯口的上升下降呼叫按钮、轿厢内楼层选择按钮、上升下降指示、各楼层到位行程开关组成。
  2. 电梯上升途中只响应上升呼叫，下降途中只响应下降呼叫，在二楼与三楼反方向的呼叫均无效（一楼与四楼除外）。
  3. 具有呼叫记忆、内选呼叫指示功能，当呼叫执行完成解除锁定。
- **I/O 分配**：共 30 个点，见 `experiment-05-elevator/IO分配表.md`
- **视频**：`experiment-05-elevator/media/demo.mp4`
- **说明**：程序为课程提供的参考程序，本人负责电气接线、I/O 分配、传感器与执行器联调、功能验证与故障排查。
